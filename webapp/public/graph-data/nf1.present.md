# neurofibromatosis type 1

Neurofibromatosis type 1 (NF1) is a clinically heterogeneous, neurocutaneous genetic disorder characterized by café-au-lait spots, iris Lisch nodules, axillary and inguinal freckling, and multiple neurofibromas.

- **Onset:** Infantile onset
- **Inheritance:** Autosomal dominant inheritance, Sporadic
- **Gene(s):** NF1, RNF135
- **Also known as:** Neurofibromatosis 1; neurofibromatosis 1; neurofibromatosis type i; NF1; Nf1-Microdeletion syndrome; nonmosaic neurofibromatosis type 1; nonmosaic NF1; peripheral neurofibromatosis
